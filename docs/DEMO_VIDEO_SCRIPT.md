# DiskRipper Demo Video Script

## Video Title: "DiskRipper — Next Generation Media Backup"
## Duration: 3-4 minutes
## Style: Screen recording with voiceover

---

### Scene 1: Introduction (0:00 - 0:30)

**Visual:** Desktop with DiskRipper icon. Click to launch.

**Voiceover:**
"Welcome to DiskRipper — the next generation media backup software. Whether you're archiving your music collection, backing up old software discs, or preserving home videos, DiskRipper makes it simple and reliable."

**On-screen text:** DiskRipper v0.1.0 | Open Source | Cross-Platform

---

### Scene 2: Drive Detection (0:30 - 1:00)

**Visual:** Main window opens. Click "Refresh" button. Drive list populates.

**Voiceover:**
"When you launch DiskRipper, it automatically detects your optical drives. Just click Refresh to scan for connected drives. You'll see the drive letter, type, and whether a disc is inserted."

**Highlight:** Drive card showing "DVD-ROM" with "Disc Present" badge

---

### Scene 3: Creating a Disc Image (1:00 - 1:45)

**Visual:** Select drive. Click "Create Image". Set output path. Click "Create Image" button. Progress bar appears in Jobs tab.

**Voiceover:**
"To create a disc image, select your drive, choose 'Create Image', and set the output path. DiskRipper will read every sector and save a perfect copy as an ISO file. You can monitor progress in the Jobs tab — it shows bytes processed, speed, and estimated time remaining."

**Highlight:** Progress bar, speed indicator, ETA

---

### Scene 4: Extracting Files (1:45 - 2:15)

**Visual:** Switch to "Extract Files" mode. Set output directory. Click "Extract Files". Files appear in output folder.

**Voiceover:**
"For data discs, you can extract individual files instead of creating an image. DiskRipper reads the filesystem — ISO 9660, UDF, or Joliet — and copies files while preserving the directory structure."

**Highlight:** File tree in output directory

---

### Scene 5: Audio CD Ripping (2:15 - 2:45)

**Visual:** Click "Audio CD" tab. Click "Load Tracks". Select track 1. Set output path. Click "Extract Track to WAV".

**Voiceover:**
"Audio CDs get special treatment. DiskRipper reads the Table of Contents to identify tracks, then extracts them as high-quality WAV files. Jitter correction ensures bit-perfect copies."

**Highlight:** Track list, duration display, WAV output

---

### Scene 6: Verification (2:45 - 3:15)

**Visual:** Go to "Verify" tab. Select drive. Enter image path. Click "Verify Image". Green checkmarks appear.

**voiceover:**
"After ripping, you can verify the image against the original disc. DiskRipper compares SHA-256 checksums sector by sector. Green means the data matches — your backup is perfect."

**Highlight:** Verification results with green checkmarks

---

### Scene 7: Settings & CLI (3:15 - 3:45)

**Visual:** Open Settings tab. Show various options. Switch to terminal, run `diskripper list-drives`.

**Voiceover:**
"Customize DiskRipper in the Settings tab — adjust read speed, retries, and more. For automation, the command-line interface lets you script ripping jobs."

**Highlight:** Settings panel, terminal with CLI output

---

### Scene 8: Conclusion (3:45 - 4:00)

**Visual:** DiskRipper logo. Links to GitHub, documentation.

**Voiceover:**
"DiskRipper is open source, cross-platform, and free forever. Download it today at github.com/LoopyLuci/DiskRipper. Preserve your media — one disc at a time."

**On-screen text:** github.com/LoopyLuci/DiskRipper | MIT License
